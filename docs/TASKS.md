# 只读解析与模型任务

“设置 → 日志”显示最近 200 项内容提取和模型生成记录，可查看、刷新、明确取消或重试。后台扫描状态和重新扫描入口也在此处；前台进度通知不提供取消按钮。历史“原件已入库”回执不适用于当前只读引用模式。

日志中的“取消任务”仅作用于选中的单项记录；批量选择的其他文件继续处理，已完成的结果保留。

启动先显示上次目录记录，后台核对本机 Codex 项目并刷新当前及已浏览目录的有界索引，不扫描所有正文。缓存损坏或来源不匹配时重新发现；缓存本身不允许解析或访问原件。目录核对后，文件解析在后台执行，不占用全局操作状态，失败可在日志中重试。关闭应用停止本窗口的后台工作，下次启动重新扫描。

自动处理仅在应用打开且对应作用域已授权时运行；独立于共享开关。同一输入失败、取消或中断后不自动重试。手动生成仍需预览并确认发送片段。每日请求限额和控制说明见[风格与记忆](CONTEXT.md)。

项目扫描只读目录元数据，登记引用只保存来源记录，两者均不自动解析。只有用户明确选择文件并发起解析，才对原路径计算稳定校验、排队并启动受限工作进程；没有上传、复制、快照或原文件写入步骤。解析失败、取消、超时或应用退出均不删除原文件。

| 状态 | 含义与下一步 |
| --- | --- |
| 未解析 / referenced | 只有目录/引用信息，不表示已读取正文、备份或完成提取 |
| 待提取 / 待生成 | 已由用户发起，等待应用处理名额，可取消 |
| 处理中 | 有效任务正在处理，可取消 |
| 完成 | 任务结果已提交；还需核对具体提取状态，空文档、扫描、加密或不支持不能当作成功提取 |
| 失败 / 已取消 | 不自动重试，可在应用显式操作；源文件变化时先核对当前来源 |
| 已中断 | 模型请求可能已发送，重新预览并确认后才可重试，可能再次计费 |
| 来源已变化 / 缺失 / 不可读 | 旧片段不可作为当前原文使用；核对原路径并显式重新解析，不从缓存恢复原件 |

来源、项目、校验版本或许可改变后，旧任务不能提交结果或恢复已撤回内容。解析前及结果提交时重新核对来源；源文件变更/移动后不能静默把旧任务用于新文件。模型候选仍需人工检查与采用，不能直接覆盖人工记忆；应用自己的记忆可编辑、关闭或删除。

这里的后台来源失效以检测到的变化为前提：扫描只看 size/mtime，不逐文件重算哈希；选择已解析文件详情时才读该文件重算 SHA-256。上下文使用元数据失效检查和已有片段，没有实时监视或每次读取全量哈希保证，同 size/mtime 的外部变更可能尚未被发现。显式解析任务自身的校验不能被描述为对所有文件持续校验。

## 启动、取消与退出

恢复已有任务与扫描新文件是两件事。仅已由用户明确发起、仍满足来源及许可条件的本地任务可按持久任务规则有限恢复，不因启动、刷新目录或结束钩子新建解析工作。异常退出的既有本地提取最多自动尝试 2 次，明确失败或取消不自动恢复。失主模型任务标为中断，不自动重发；已有落盘候选仅修复回执。

关闭窗口停止本窗口工作，关联解析进程随之结束；未变更原件仍在原目录。其他打开的窗口/MCP 有各自生命周期。没有任务时不保留解析进程，不持续扫描目录。来源失效和 schema4 恢复后取消的任务不会因为重开窗口而把旧缓存恢复。

在 AI 配置关闭远程发送，会撤销等待及处理中的模型任务并保留关闭状态；已经发出的网络请求无法保证撤回，但迟到结果不能进入候选。重新开启不自动重发旧请求。共享、原件路径许可和远程发送相互独立；扫描、解析、安装 MCP/skill 均不连带开启它们。

## 资源和格式限制

同一应用库同时最多一个解析进程、一个模型请求。解析按需启动，期限 30 秒、进程提交内存上限 256 MiB、低优先级、CPU 硬限制 25%；IPC 请求/回复上限分别为 64 KiB/1 MiB，这不是源文件大小上限。设置进程限制成功后才发送路径，父进程异常退出由 Windows Job 结束子进程。

正文预览含定位标签最多 65,536 个 UTF-16 字符，截断应明确提示。PDF 输入最多 16 MiB/256 页，另有单流、累计解码和递归限制；Office ZIP/XML、文本编码及不可提取状态详见[格式说明](FORMATS.md)。解析不执行宏、脚本、正文指令或外部链接，不调用外部 PDF 阅读器。无法在预算内处理时报告限制或工作进程失败，不放宽为无限解析。

这些是实现限额和隔离措施，不是完整安全沙箱，也不是整机 CPU、主界面流畅度、启动时间或大库检索的达标报告。256 MiB 指提交内存，不等于任意工作集指标；跨机器、长期大库和实际交互性能仍待后续验收。

## CLI/MCP 与恢复

在完整运行目录可查询或取消任务，自定义应用库另加 `--data-root`：

```powershell
.\bridge\Amifolio.Bridge.exe tasks
.\bridge\Amifolio.Bridge.exe task-cancel '<任务 ID>'
```

默认桥接的 `task-retry`、`process-tasks` 会要求回到应用明确操作，不能作为自动解析入口；MCP 没有启动解析或发送模型请求的工具。`submit` 的 `referenced` 是引用登记回执，`status` 用于核对来源和提取状态，不能把它当作归档成功。结束钩子只有限刷新发现/既有引用索引，不读取正文或执行任务。详见[扫描与接入](COLLECTION.md)。

当前数据库 schema4；应用索引与任务可进入兼容备份，但不备份项目原文件。恢复后旧引用校验和预览清空、未完成引用提取取消，须重新核对原路径并显式解析；共享及远程发送关闭，模型任务不自动外发。默认桥接不开放旧备份/恢复命令，具体边界见[数据恢复说明](STORAGE-RECOVERY.md)。
