# 风格、记忆与通用偏好

阶段9起，产品入口使用双模式会话学习，LearningPolicy 为共享授权依据。以下旧版“按文件生成候选、通用偏好”说明仅作为历史兼容设计；这些入口已停用，旧资料在“设置 → 旧资料”只读查看，不参与新学习。已保存的AI配置保留，供授权的后台会话整合使用。

Amifolio 只读引用本机 Codex 项目。扫描仅列目录；选中文件并点击“解析所选”后，应用才读取原件片段。生成不修改原文件，也不上传整个项目。

## 手动生成

1. 在“AI 配置”保存服务地址、模型和 Key，开启远程发送。
2. 在“风格与记忆”选择项目，点击“生成候选”，核对目标服务和发送片段后确认。
3. 候选只在应用内待确认，不直接提供给 Codex。核对来源后点击“采用候选”，或手动编辑正式文档。

学习证据不足时可能没有风格或记忆候选；不会从 Codex 的行文推断用户人格或偏好。采用的候选保留来源版本；检测到来源变化会撤回。编辑派生文档需明确确认“保存为人工文档”，解除来源关联后由用户维护。确认期间候选更新时，必须重新查看后采用。

## 自动处理

在对应作用域点击“自动处理”，分别设置：

| 开关 | 作用 |
|---|---|
| 自动生成记忆与风格候选 | 对已解析有效片段提出候选，不覆盖人工文档 |
| 自动生成概要与总结候选 | 对相同范围生成概要/总结候选 |
| 允许此作用域自动发送片段 | 允许应用打开时使用已保存AI配置发送这些片段 |
| 向Agent提供上下文 | 共享正式文档；与生成、发送独立 |
| 提供原件路径 | 允许发布原路径定位信息；与共享和发送独立 |

所有自动开关默认关闭。只在应用打开时每30秒检查已启用作用域；输入未变不重复发送。没有有效片段、保存的模型配置或独立远程许可时不会发送。关闭窗口或关闭远程发送会取消当前自动任务，不新增常驻服务。

关闭自动生成只停止后续生成并清除不适用的待确认候选，保留已经采用的文档。需要撤回提供给 Codex 的内容时，停用文档或关闭共享。

自动请求全应用每天最多8次（UTC日期），至少间隔60秒，并发1；每次最多24段/24KB片段、64KiB请求、2048输出token及60秒超时。失败、取消或进程中断后的同一输入不会自动重发；需要时手动预览后生成。不同服务的价格不同，此限制不等于固定金额上限。恢复旧备份不降低本机当前同日计数；清除整个应用数据不提供防篡改计费保证。

正式文档可“修改/保存/取消”、删除或单独停用。停用保留内容并从共享入口移除；删除后后台不会自动恢复。共享关闭不等于自动生成关闭，请分别管理开关。全局不会自动读取所有项目正文；跨项目只使用下列确认后的通用偏好。

## 通用偏好

1. 在项目作用域打开“通用偏好”，单独开启该项目参与。参与不打开项目共享或远程发送。
2. 可使用已生成的风格/记忆候选作参考，改写为通用表述，再选来源并添加候选。例如“回答时，请先列依据，再说明待确认项”。
3. 核对候选后点击“确认偏好”。只有确认且启用的条目，才会出现在全局“通用偏好”文档；对 Codex 的提供仍由全局共享开关控制。
4. 可拒绝、删除、停用、改写后重新确认，或撤销整个项目参与。撤销后不会由迟到模型结果或重新解析自动恢复原确认。

内部台账保留项目、来源校验/版本、候选校验和确认时间；共享文档仅包含确认后的通用表述。已知项目标识、路径、明显凭据、长原文和指令标记会被拦截，但规则不能理解所有专有事实，确认前仍需人工核对。条目依赖的任一来源失效时都会撤回，人工全局文档不连带删除。

`preferences.md`是受管投影，请在“通用偏好”入口修改条目。文档本名显示在页面路径处，列表使用功能名。

不建议直接编辑发布目录中的受管文档。外部改动的派生文档仍按来源撤回；改动的偏好投影不视为确认。冲突文本最多每文档256KiB留在应用私有 `context-state/<作用域>/state.json` 的 `ExternalEdits` 字段，并随应用备份保留，不提供给Codex或模型。需要解除来源关联时请使用应用内明确的人工保存流程。

## 新鲜度与恢复

普通扫描/自动检查不逐文件读取正文或哈希；明确预览、实际生成、提出或确认偏好时会核对本次依赖，生成后再次核对。没有实时目录监视承诺。检测到变更后需要用户重新解析。

备份包含应用索引、人工文档、偏好台账及自动计数，不备份原件。恢复后共享、路径、自动发送和项目参与均关闭，引用未解析，候选/派生偏好失效；私人条目文本保留供查看与重新核对。外部已经读取或自行导出的内容无法追回。


## 阶段8：会话学习

从“环境配置”或“风格与记忆”打开“会话学习”。逐项目保存采集、整合、自动启用和共享许可；全局只接收参与项目的通用偏好。所有新增许可默认关闭。启用旧版自动生成、保存 API Key 或安装接入，都不会代替这次授权。旧文件候选与会话画像分别显示，避免把旧文件候选误当作已核实的会话记忆。

每回合只记录一段概述、结果和文件用途，配以可核对的用户引文。服务端匹配 Codex 会话、回合和项目目录；概述及文件用途仍标明 Agent 报告。无法核对的来源保留为待核实，不计入可学习回合。支持经本机CLI核对的顶层 `UserMessage` 事件，须匹配会话、回合及GUID标识，且内容为完整纯文本。助手、工具、子Agent、来源不明或缺少标识的记录不采信；多模态回合暂不自动学习。

- 会话内模式：无需 Amifolio API Key；skills 提交概述，达到阈值后由当前 Agent 领取和整合。
- 后台模式：需保存有效 AI 配置，另行授权向该服务发送本项目概述及必要短引文。默认累计5回合；可观察到的最后用户回合后至少120秒再处理，不监听全局键鼠。24小时积压可在下次打开时处理。应用关闭不运行后台定时器。
- 两种模式共用同一事务数据库、回执、水位和租约，不重复累计。切换模式、撤回许可或来源失效会使旧结果失效。失败、中断不静默重试，可在处理日志明确重试。

画像分为观察、启用、停用及删除。明确长期且有充分完整语境的表达可自动启用；普通偏好需多个独立回合支持，临时或未知内容保留观察。全局需来源项目参与，且满足跨项目依据或明确的全局表达。自动规则保守且有限，不承诺理解所有语言、同义词或秘密形式。

可查看依据和适用条件，点击“修改”后编辑，保存时形成独立人工内容并锁定；取消恢复原内容。支持停用、删除和撤销修改。人工内容不会被后台覆盖。删除保留抑制标记，改写措辞和恢复旧备份不能自动恢复同维度条目；撤销来源会撤回依赖它的自动条目。

`learning/state.sqlite` 是会话学习的权威数据；`learning/shared/.../START.md` 及分层文档只是自动更新的共享快照，不要直接编辑。仅共享启用且适用的层，最多24项；不导出候选、原始引文和私有来源台账。需要同时开启会话学习共享和该范围的原有共享总开关。关闭任一共享会撤回应用共享入口；外部已经读走的内容无法追回。

恢复备份保留人工修订、删除和抑制记录，但关闭学习、共享、远程及参与许可，取消租约并使旧自动依据失效。重新授权后仅接收授权后的新回合；不会重新读取历史对话来自动补全画像。

“风格与记忆”显示全库常用容量；“历史记录”按当前作用域分页查看概述和画像，每页50条。转入历史不会删除正文、改变状态或扩大共享；恢复到常用后可在详情中修改画像。删除会移除正文并留下防重放记录。常规页面只载入有界窗口，历史入口用于查找更早的记录。
