# Amifolio 1.1.1

Windows 11 x64 预发行版，从 v1.1.0 更新。此版本由对应历史候选源码重新构建。

## 更新内容

- 重做风格样张的视觉和编辑体验。可以直接选中页面上的元素，调节字体、颜色及间距，预览与已保存的创作偏好相连。
- 作品卡优先展示缩略图或内容预览，并保留打开原件与核对来源的入口。

## 下载与升级

下载 `Amifolio-1.1.1-win-x64.zip` 和配套 SHA-256 文件。完整解压后运行 `desktop/Amifolio.exe`。需要 .NET Desktop Runtime 10、Windows App Runtime 2.6.5、Visual C++ x64 运行库和 Edge WebView2 Runtime。运行包未签名。升级前关闭旧应用，保留旧运行目录并备份应用数据。详见[安装、升级与排查](../RELEASE.md)。

## 验证范围

Windows 本机构建与原生场景覆盖桌面应用。真实 Codex 桌面的普通文档附件、实时偏好注入与完整空闲计时仍待验收。该版本作为预发行提供。
