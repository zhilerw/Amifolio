# Amifolio 1.1.2

Windows 11 x64 预发行版，从 v1.1.1 更新。此版本由对应历史候选源码重新构建。

## 更新内容

- 首屏新增「这个项目现在」，展示生效偏好、继承的全局字段、最近作品及待确认建议。快捷操作打开相应作品卡或候选证据。
- 范例展示缩略图或片段、沿用部分和来源。原件缺失时仍可核对来源并移除关联。
- 作品页优先展示可信的 Codex 会话标题，UUID 保留在详情。目录浏览、扫描和手动解析移到「设置 → 高级 → 项目文件」。
- 插件页默认呈现本机接入状态与一个操作。独立 MCP、Skills、钩子和接入段落维护收进「迁移与兼容」。

## 下载与升级

下载 `Amifolio-1.1.2-win-x64.zip` 和配套 SHA-256 文件。完整解压后运行 `desktop/Amifolio.exe`。需要 .NET Desktop Runtime 10、Windows App Runtime 2.6.5、Visual C++ x64 运行库和 Edge WebView2 Runtime。运行包未签名。升级前关闭旧应用，保留旧运行目录并备份应用数据。详见[安装、升级与排查](../RELEASE.md)。

## 验证范围

Windows 本机构建与原生场景覆盖桌面应用。真实 Codex 桌面的普通文档附件、实时偏好注入与完整空闲计时仍待验收。该版本作为预发行提供。
