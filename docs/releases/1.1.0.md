# Amifolio 1.1.0

Windows 11 x64 预发行版，从 v1.0.0 更新。此版本由对应历史候选源码重新构建。

## 更新内容

- 新增 Codex 本地插件市场，可安装 Amifolio 插件、启用 MCP，并在 Codex 内审核和信任结束钩子。
- 「作品」聚合已识别的 Codex 上传件和交付物，可跳转到来源或设为范例。首屏风格样张用于编辑全局和项目偏好。
- 「指令」支持查看、编辑、核对差异与撤销 AGENTS.md 变更。提供只读的 Codex 原生记忆浏览入口。

## 下载与升级

下载 `Amifolio-1.1.0-win-x64.zip` 和配套 SHA-256 文件。完整解压后运行 `desktop/Amifolio.exe`。需要 .NET Desktop Runtime 10、Windows App Runtime 2.6.5、Visual C++ x64 运行库和 Edge WebView2 Runtime。运行包未签名。升级前关闭旧应用，保留旧运行目录并备份应用数据。详见[安装、升级与排查](../RELEASE.md)。

## 验证范围

Windows 本机构建与原生场景覆盖桌面应用。真实 Codex 桌面的普通文档附件、实时偏好注入与完整空闲计时仍待验收。该版本作为预发行提供。
